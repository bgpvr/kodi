Automatic Kodi PVR setup for BGPVR

This repository provides the official BGPVR Kodi add-ons. BGPVR Setup configures Kodi’s IPTV Simple Client for Live TV and the guide. The BGPVR add-on adds Films and Series, played by Kodi’s own player. Play links use a secure stream token, never your password.

BGPVR provides software only. This repository does not provide IPTV links, playlists, TV channels, streams, subscriptions, streaming services, or media content.

Install in Kodi (no download needed)

  1. Kodi › Settings › System › Add-ons: turn on Unknown sources.
  2. Kodi › Settings › File manager › Add source: type https://k.bgpvr.com, name it BGPVR, OK.
  3. Add-ons › Install from zip file › BGPVR › repository.bgpvr-1.0.1.zip.
  4. Install from repository › BGPVR Add-on Repository: Services › BGPVR Setup (Live TV + guide) and Video add-ons › BGPVR Live TV (Films & Series).
  5. Open BGPVR Setup settings: server https://pvr.bgpvr.com, your username and password › Save & Restart Kodi.
  6. Live TV: Kodi › TV. Films & Series: Add-ons › Video add-ons › BGPVR Live TV.

Repository files

  • repository.bgpvr-1.0.1.zip (install this first)
  • plugin.video.bgpvr-1.1.1.zip
  • service.bgpvr.setup-1.0.3.zip
  • addons.xml · addons.xml.md5

Updates arrive automatically once the repository is installed.

На български

  1. Kodi › Настройки › Система › Добавки: включете Непознати източници.
  2. Настройки › Файлов мениджър › Добави източник: https://k.bgpvr.com, име BGPVR.
  3. Добавки › Инсталиране от zip файл › BGPVR › repository.bgpvr-1.0.1.zip.
  4. Инсталиране от хранилище › BGPVR Add-on Repository: BGPVR Setup (телевизия и програма) и BGPVR Live TV (филми и сериали).
  5. В настройките на BGPVR Setup: адрес https://pvr.bgpvr.com, потребителско име и парола › Save & Restart Kodi.

Support

If setup fails, check that your BGPVR account is active, your package includes this access, and https://pvr.bgpvr.com opens on the Kodi device. After a password change, restart Kodi once.
